# The frozen configuration

* **Preset:** `amm_optimizer.presets.get("c46")`.
* **Configuration hash:** `2153948ebed51150` (`ATMConfig.config_hash()`). The hash depends on the
  `Variant` schema, so a field added later changes it without changing behaviour; the
  characterisation snapshots (`tests/characterisation.json`) pin the behaviour bit for bit.
* **Frozen on 2026-10-22.** The algorithm of the paper does not change after that date; later
  releases may add packaging, documentation and opt-in options, and each opt-in defaults to the
  frozen behaviour.
* **Environment of the bit-exact snapshots:** Python 3.12.10, NumPy 2.5.4, SciPy 1.18.1,
  Windows-AMD64, one BLAS thread. Bits are reproducible in that environment on the same CPU
  family; on other CPUs, operating systems and Python versions the results are statistically
  equivalent, not bitwise (see `tests/conftest.py`, marker `snapshot`).
* **Scope of the evidence:** noiseless, continuous, box-constrained problems, budgets of 10 to
  1000 times the dimension, COCO/bbob. The pre-registrations, batch notes and result files of the
  development are kept in a separate research archive.
