## The project

AMM (Adaptive Multi Mode) is a derivative-free optimizer for continuous black-box problems. It reads the function with
cheap probes and routes the evaluation budget to a classical algorithm. It grew out of an earlier optimizer, ATM
(Adaptive Two Mode), whose sampler is one stage inside AMM. The code is Python, depends on NumPy and SciPy, and is
developed with a preregistered protocol that the [research log](/research-log/) describes.

This site states every result next to its status: final, in-sample development data, or pending. The
[limits page](/limits/) lists where AMM loses.
